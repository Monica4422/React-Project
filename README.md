# e-GRCP Platform

A production-style enterprise governance, risk, compliance and procurement portal built with React, Vite, Redux Toolkit, React Router, Material UI and Recharts.

## Features
- Authentication with protected routes and role-aware access
- Executive dashboard with interactive charts
- Procurement workspace, vendor governance, risk center and compliance monitoring
- Audit center, reports hub and settings module
- Redux Toolkit slices, Redux Persist and Axios client integration
- Lazy loading, error boundary and responsive MUI layouts

## Development
- npm install
- npm run dev
- npm test
- npm run build

## Deployment
Deploy the built application to Vercel or Netlify with the standard Vite build output.
